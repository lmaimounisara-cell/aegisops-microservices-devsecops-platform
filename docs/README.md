# AegisOps Portfolio

A static portfolio for the AegisOps cloud-native DevSecOps and GitOps project.

## Contents
- `index.html` — responsive portfolio with interactive evidence gallery and architecture image viewer.
- `assets/evidence/` — 26 curated evidence captures plus the supplied architecture diagram. No unrelated screenshots are included.

## Publish with GitHub Pages
1. Download and extract this ZIP.
2. In `lmaimounisara-cell/aegisops-microservices-devsecops-platform`, upload `index.html` and the entire `assets` folder into the repository's `docs/` folder. Preserve the paths.
3. Open **Settings → Pages** in that repository.
4. Set the source to **Deploy from a branch**, choose `main` and `/docs`, then save.
5. Wait for the Pages deployment and open the URL shown in Settings → Pages.

## Evidence and attribution
The site links only to the AegisOps repository. Screenshots from implementation tools are shown as evidence and are not linked to a separate repository. The architecture is labelled as a target design; a diagram alone is not treated as proof that every component is deployed. Captured security scan findings are presented transparently.
